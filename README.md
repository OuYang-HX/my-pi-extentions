# My Pi Extensions

Personal extensions for [pi-coding-agent](https://github.com/earendil-works/pi-coding-agent).

**GitHub**: https://github.com/OuYang-HX/my-pi-extentions
**Local path**: `~/my-pi-extentions/`
**Installed extensions path**: `~/.pi/agent/extensions/`

## Extensions

| Extension | Description |
|-----------|-------------|
| [llm-stats](./llm-stats/) | Tracks LLM API request counts |

## Installation

Each extension has its own `install.bat` (Windows) or `install.sh` (Linux/Mac).

Or manually copy to `~/.pi/agent/extensions/<extension-name>/`
